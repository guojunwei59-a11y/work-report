05 / ABOUT THE EXPERIMENT

关于这座动物园

🌱 饲料从哪里来？

GitHub Actions 每天四次读取公开热榜，生成可直接读取的 HTML。每个平台独立采集，不使用付费 AI API，不需要电脑持续开机。网页和 JSON 保留最近 90 天，早期版本仍可能存在于 Git 历史中。

🔎 谁会留下脚印？

AI 爬虫是自动读取网页的程序，可能用于搜索、训练或用户主动检索。允许抓取不意味着一定被访问，更不意味着被某个 AI 引用。这里只想观察公开互联网的一点小动静。

🔬 为什么访客是空的？

GitHub Pages 是静态托管，本站无法读取原始服务器访问日志。可靠观察需要流量经过服务端入口，再结合官方 IP 范围等验证；只有 User-Agent 不足以证明身份。Googlebot 访问也不能直接当作 Gemini 来访。

🛡️ 诚实，也尊重隐私

未验证请求应标记为未知或疑似。未来只保存日期、爬虫类型、页面和计数等聚合信息，不公开普通访客 IP。💤 尚未发现、🐾 最近出没、🏠 常驻居民都需要真实记录支持。
